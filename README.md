# E-commerce Consumer Behavior Analysis

## Project Overview

This project explores consumer purchasing behavior through
customer segmentation and discount-related analysis.

It combines data cleaning, business indicators, machine learning,
Dash visualization, and automated processing with GitHub Actions.

## Dataset

Dataset: Ecommerce Consumer Behavior Analysis

Source: https://www.kaggle.com/datasets/salahuddinahmedshuvo/ecommerce-consumer-behavior-analysis-data

Original file: Ecommerce_Consumer_Behavior_Analysis_Data.csv

The dataset contains 1,000 records and 28 columns describing
customer characteristics, purchasing behavior, marketing engagement,
and customer satisfaction.

## Research Questions

1. What customer segments can we identify from purchasing behavior,
   and how should marketing strategies differ across these segments?

2. How do purchase amount and purchase frequency differ between
   discount users and non-users across customer groups?

## Planned Methods

- Data examination and cleaning
- Descriptive analysis and business indicators
- Customer clustering and evaluation
- Interactive dashboard using Dash
- Batch processing and report generation using GitHub Actions

## Data Quality Notes

- Purchase_Amount requires conversion from text to numeric values.
- Time_of_Purchase requires conversion to a date format.
- "None" is a valid category in social media influence and ad engagement.
- Occupation and Return_Rate require clarification before analysis.
- Each customer appears once, limiting longitudinal analysis.
